## Rebuild from the expanded research package

The project root is the directory containing `output/control-v6`, the historical `output/analysis-*` directories and `evidence/`. Use the Python packages in `requirements-report.txt`; recorded versions are in `dependency-versions.json`. From this report directory:

```sh
python source/plot_v6_results.py --analysis ../control-v6/analysis/v6-analysis.json --analysis-sha256 fc2e7b4c2c9c0184fbf613ebca019b1787dad3c55d3e30f88e66eb0b7acbb277 --outdir figures --pdftoppm /path/to/pdftoppm
python source/prepare_final_input.py --project-root ../.. --final
python source/build_report.py --input source/report-input.json --out rebuilt.docx --project-root ../.. --artifact-root ../..
```

For an exact retained-input rebuild, skip the figure and input regeneration commands and use the saved hash-bound assets. Figure re-rendering across different dependency versions may change file bytes; do not silently replace the retained figure evidence. `prepare_final_input.py` uses the exact reviewed V5 input and `integrate_closed_results.py`, which accepts only the pinned closed V6 evidence. It preserves all historical numeric table and figure blocks. Its default mode remains an explicitly incomplete historical preparation; use `--final` for closed observations. The document builder checks every input hash, requires readiness, rejects unresolved markers and enforces a 150–250 word abstract. All paths inside the input are relative to the expanded package or this source directory.

No authoring script starts inference, reads credentials, retries calls, alters study evidence or publishes anything. `authoring-evidence-staging.json` records the byte copies used to combine old and new local evidence during authoring. That staging directory is unnecessary in the expanded package, where canonical relative paths are already present. `history-v5/`, draft layouts, synthetic charts and temporary build roots are not required and are excluded from the final archive.

## Rendering and review

PDF rendering additionally needs LibreOffice, Poppler, the Old Standard TT template font and the Documents `render_docx.py` tool. In the authoring environment only the bundled LibreOffice was used, through the bundled Python runtime; no desktop office process was used or terminated. The renderer is an optional external dependency, not included in the archive. To render a rebuilt DOCX:

```sh
python source/build_report.py --input source/report-input.json --out rebuilt.docx --project-root ../.. --artifact-root ../.. --render --renderer /path/to/render_docx.py
```

The editable DOCX remains usable without these rendering tools. `visual-review.json` records inspection of every final page under `../renders/`; it applies only to the exact retained PDF/DOCX hashes. Rendering a replacement requires a new visual review. References and appendices follow the main text; the main-text limit is eight pages. The current final audit records the actual count. The source content review and portable rebuild proof are separate from visual review. Offline research-package reproduction is a further validation, reported by the package verifier rather than inferred from authoring success.

## Figure

`plot_v6_results.py` uses ReportLab's chart library and embedded Vera fonts, with vector PDF/SVG and a 300-dpi PNG generated by Poppler. It selects every fixed arm in both models and objectives on common complete cases, checks plotted counts against individual analysis rows, and binds the analysis, closure and plotting script. The main Qwen harmful comparison uses three complete cases; the all-observed seven-episode baseline has different coverage and is not plotted. No historical successor response supplies the V6 baseline. The final figure audit covers the exact PNG/PDF/SVG bytes. Every valid episode, including verification alone, has zero observed outsider loss and joint harm; the figure measures coordination gains.

## Portable authoring check

`check_portable_rebuild.py --project-root /path/to/expanded/package --docx ../inherited-collusion-v6.docx` copies the bound evidence and source into a temporary root, denies reads from the original root and report, disables networking and child processes inside the rebuild, then regenerates the input and DOCX. `portable-rebuild.json` records matching input bytes and all DOCX package members. It does not rerender the PDF or substitute for full study-package verification.
